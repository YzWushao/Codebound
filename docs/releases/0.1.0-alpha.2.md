# Codebound 0.1.0-alpha.2

Windows x64 的 Python 编程闯关 Alpha，包含「序·幕：Byte 苏醒」20 关。每关提供讲解、示例区、起始代码和三级提示。

## 安装

下载 `Codebound-0.1.0-alpha.2-Setup.exe` 安装后即可游玩，无需安装 Python、Node.js 或从源码构建。安装包内含离线 Python 运行环境。下载校验值见 `SHA256SUMS.txt`。

## 本次更新

- 启动 Python 前校验运行资源的大小与 SHA-256，缺失或损坏时指出具体文件。
- 预先加载并校验 Python 标准库，再从内存提供给解释器。
- 初始化失败时保留阶段、原始错误和 Python 标准错误，可展开「查看运行器诊断」，便于排查 `Program terminated with exit(1)`。
- 存档格式与已有 Alpha 保持兼容，进度和草稿继续保存在本机。

这是预发行版本。C/C++ DLC、后续两幕和自动下载安装更新尚未提供。截图所报问题尚需在原出错电脑上复测，本版为该问题提供资源检查与可读诊断。
